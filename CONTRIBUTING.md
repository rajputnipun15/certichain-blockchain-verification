# Contributing to CertiChain

We welcome contributions to **CertiChain**!

## How to Contribute

1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/my-feature`).
3. Commit your changes following conventional commits format (`feat: ...`, `fix: ...`).
4. Ensure all unit and integration tests pass (`npm test --prefix server`).
5. Open a Pull Request.

Thank you for helping build cryptographic trust in academic credentials!
