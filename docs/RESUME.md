# CertiChain Resume & Portfolio Highlights

## 1-Line Description
A production-grade, full-stack **Blockchain-Based Certificate Issuance & Verification Platform** featuring a custom Proof-of-Authority (PoA) ledger engine, SHA-256 document byte hashing, Ed25519 digital signatures, and Merkle tree inclusion proofs.

## 3 Resume Bullets

- **Engineered a custom Proof-of-Authority (PoA) blockchain engine in TypeScript**, implementing SHA-256 block hashing, Merkle tree root calculation, and Ed25519 digital keypair signatures to eliminate degree forgery.
- **Built an automated cryptographic verification engine and PDF generator** in Node.js & React, performing sub-100ms client & server PDF byte hashing, QR code generation, and real-time ledger audit checks.
- **Designed a high-impact Web3 glassmorphism UI & Tamper Detection Laboratory** using React, TypeScript, Tailwind CSS, and Framer Motion, enabling recruiters to perform 1-click verification and interactive hash divergence audits.

## Technologies Used
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide Icons, Recharts, Canvas-Confetti
- **Backend**: Node.js, Express, TypeScript, Prisma ORM, JWT, bcryptjs, pdf-lib, QRCode
- **Blockchain Core**: SHA-256 Hashing, Merkle Trees, Ed25519 Keypairs, Block Linkage Validation, PoA Consensus
- **Database & DevOps**: PostgreSQL, SQLite, Vitest, Docker, Docker Compose, GitHub Actions CI
